# Child Center 0.6.4 — approved administration and operator UI

Extension-only presentation release over 0.6.3. Storage stays at revision 0015;
no new migration, business-rule changes or Core/Agent modifications.

- Administration: Barsy Setup / Tables / Troubleshooting. Connection, live delivery
  and time measurement are distinct steps. Active measurement is a status, not a
  disabled button. Obsolete account/table descriptions are corrected.
- Test-mode parent queues explain that live delivery must be enabled. Manual client
  IDs and account verification are grouped under troubleshooting. Enabling live
  delivery asks for confirmation and explains the effect on queued parents.
- Operator: account list with child/table search and open/checkout filters on the
  current page; selected account combines time, consumption and finish/payment.
  Finishing preserves selection. Payment preview hides unrelated consumption
  controls. Uncertain commands retain their existing recovery/idempotency flow.
- Historical stays and reports remain accessible; new accounts are not duplicated
  as separate active-visit cards on the currently loaded account page.
- English/Bulgarian labels, existing theme tokens and responsive layouts retained.

The existing 0.6.3 payment limitations and Barsy timer capability gate still apply.
No real payment or fiscal operation was used for UI validation. Screenshots and
browser checks use synthetic local responses.

Upgrade the existing installation through the extension installer; do not erase
the extension database or recreate its configuration for this UI update.
The delivery folder is `.runtime/child-center-0.6.4` at the repository root.
Archive its CONTENTS, so `manifest.json` is at the ZIP root. No outer ZIP,
deployment, installation, commit or push is generated by this release preparation.
